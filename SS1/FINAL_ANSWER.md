## 📊 **UNDERSTANDING THE COUNTS**

### Why 9, not 16?

**WRONG Thinking:** 
"15 different configurations = 15 buoys" ❌

**CORRECT Thinking:**
"BC0.1, BC0.2, BC0.3 = 1 physical buoy (BC0)" ✅

### Physical Buoy Identity = Base Code + Module Count

- **BC0** = BC base + 0 modules (can add/remove shackles as needed)
- **BC1** = BC base + 1 module (different physical buoy)
- **BC2** = BC base + 2 modules (another different physical buoy)

**Shackles** = Quick reconfiguration (1h)  
**Modules** = Define the physical buoy (3h to add/remove)  
**String** = Complete buoy swap (5h)
